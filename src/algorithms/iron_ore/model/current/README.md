# 当前200–565 nm模型

五个ExtraTrees均重新训练；120个完整谱窗、240维输入、7301点统一网格。氧化矿main输出TFe/SiO2/Al2O3/TiO2，附带旧FeO列；added输出CaO/MgO/MnO/P/S；FeO_mixed覆盖氧化矿FeO，使用7500条模拟谱与320条实测谱，实测总权重99%。硫化矿main与added共同输出十项。

80条标准谱整批留出，与200–600 nm模型的训练/测试身份相同。模拟组成、工况变体与分组保留，截取谱窗后重新归一化；实测特征从原文件重新提取。原合并文件550–565 nm部分的来源仍未核实。
