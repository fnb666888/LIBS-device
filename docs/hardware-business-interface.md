# 业务层需要的硬件操作与封装待办

设备库有六类控制器。已有主测量流程使用激光器、光谱仪和状态灯。设备会话也可以按站点配置装配测距仪、空调和检测头移位变频器，三项默认关闭。

## 当前联调阶段

「仪器参数」的检测头移位电机卡片显示停机回读、输出频率、限位和故障。操作员可调整本次点动时长，发起正向或反向点动，并请求停止。已触发的该方向限位会阻止点动，点动期间的限位触发、通信失败或变频器故障会触发停止请求。点动与测量互斥。启用移位设备时，测量须确认变频器报告停机且输出频率为零。停机回读不提供检测头到位证明。

站点配置的 `motor` 可省略，默认禁用。启用后使用串口及 Modbus 地址字段。`jog_ms` 为 0 时只读，正值为 100–50000 毫秒的默认点动时长。限位输入映射可省略，也可配置两路经确认的独立输入位和极性。「重新读取」读回频率、减速时间和通讯超时。停机后可把正反向点动频率设成同一值，范围为 0.1–50.0 Hz，并受变频器上限约束。点动前确认通讯丢失停机方式，临时启用不超过 1 秒的通讯超时，回读停机且输出为 0 Hz 后恢复原值。

守护进程启动时自动核查同一条安全门禁。设备状态更新和参数保存触发重新判定，Qt 的「检测控制」展示当前结论、阻断原因和告警。设备暂未就绪时后台与 Qt 仍可启动，便于排查。固定测点通过 Qt 人工启停，开始检测和开闸前各采样并复核一次。

激光器通过 RS-232 请求取得状态，读数同时供门禁和设备诊断使用。待机时每轮读取完等待 2 秒，检测中每轮读取完等待 500 毫秒，启停阶段切换会唤醒采样。辅助设备和光谱仪状态更新触发判定时直接使用快照。IPC 的 `gate` 查询当前结论，`gate {action:"refresh"}` 可主动复核。

- 开始前，激光器和光谱仪须就绪，同时满足工艺参数、联锁和急停等条件。
- 检测中，安全信号异常或不可读、激光器或光谱仪故障时，结束任务并确认停机。三色灯、测距仪和空调的通信失败、故障、普通告警和无效读数仅显示告警。
- `MeasurementJob` 统一收尾。`status` 与 `measurement_status` 均报告 `stop_confirmation`。停机未确认时可以重试停止。设备恢复且已确认停机后，门禁自动更新，操作员可手动开始下一次检测。

Qt 从后端采样快照更新「仪器参数」各设备卡片和「实时光谱」的设备概览。光谱仪通道数和波段取自最近一次空闲枚举。各卡片的「参数说明」打开「帮助」内相应章节。

「仪器参数」同页显示六类设备。激光器和光谱仪分别保存到测量参数库，检测运行中锁定编辑。空调可直接修改上次保存的值，有连接时「重新读取」读取设备当前设定，「保存参数」写入并回读确认。空调离线时使用本机保存值，首次显示模拟初始值。串口、波特率和地址等装机参数在站点文件中配置。

仪器参数页的「开始真机连续检测」使用正式检测及其联锁。光谱仪可独立采集并保存一帧，状态灯试灯后自动恢复业务灯态。空调显示模式回读及内外风机状态，手动测试提供待机／送风、制冷、加热、除湿四个按钮。测距仪的「单次测距」读取设备，并用表单当前数值显示判定结果。空带基准、来料阈值、可测距离上下限及电机点动时长可以保存到本机，检测中保存的测距规则用于下次检测的判定预览。

当前验收重点是各设备能正常读写，以及人工启动、采集、停止、再启动能稳定重复。下节生产阶段规则保留为后续需求。

## 已确认的一期方案

一期在一个固定位置检测传送带上的铁矿石。现场有多条传送带，检测头自动移位和跨带协调留到后续。操作员在 Qt 界面开始和停止任务，`businessd` 负责设备联动。成分结果用于现场显示、留档和人工复核。以下是确认后的业务要求与接口契约，后文单独记录当前源码实现。

### 测量任务与设备联动

| 场景 | 业务行为 |
| --- | --- |
| 操作员开始 | 一次人工启停对应一个任务。使用本次任务的工艺参数和测距参数，检查设备就绪、出光门禁、有料和距离是否可测。进入实际测量时，按现有测量流程协调激光与光谱仪准备。 |
| 有效读数表明缺料或超出可测距离 | 暂停实际测量，保留当前任务，继续观测距离。在有料且距离重新进入有效范围的第一条有效新读数到来后，重新检查启动条件，通过后自动续测。 |
| 测距返回无效值 | 无效值不参与有料或可测判定，也不能触发续测。Qt 显示当前读数无效，保留任务，等待新的有效观测。通信中断按下一行处理。 |
| 测距通信中断 | 暂停实际测量并保留任务，记录原因。通信恢复后，须由操作员确认，并重新检查测量条件后才继续。 |
| 门禁不满足、激光器故障或光谱仪失联 | 拒绝进入测量，或结束已启动的当前任务并保留已有记录。排除故障后由操作员开始新任务。普通缺料或距离超窗按等待规则处理。 |
| 光谱仪在线但本发超时或通道不齐 | 本发记为剔除并记录原因。沿用现有连续失败次数上限，偶发失败可以重试，达到上限结束任务。 |
| 空调告警、失联或环境超限 | 在 Qt 显示告警并记录。空调与检测的联锁条件等设备工作范围和处置规则明确后再定。 |
| 操作员停止 | 请求停止测量，记录停止结果、任务结束时间、有效和剔除帧数。 |

测距有两个独立业务判据。有无料依据当前距离相对空带基准的变化量判断；能否测量依据实际距离是否落在有效窗口判断。基准、来料变化阈值和窗口上下限一期由人工设置，正式标定功能留到后续。这些判据属于业务层，测距驱动提供每次观测及其有效性、通信结果和可用于判断新鲜度的信息。

有原始光谱就留档。只有通道完整且通过模型质量检查的帧计为有效成分结果，其余记录剔除原因。成分仅逐帧显示，任务汇总记录任务时间和有效、剔除帧数。

### 五类设备需要提供的接口

| 设备 | 读 | 写或执行 | 给业务的结果 |
| --- | --- | --- | --- |
| 激光器 | 读工作状态、联锁、急停、故障、过温、光闸，按需读放电计数 | 按一组工艺参数准备并等就绪、执行开闸、停止并回读确认 | 状态是否可读，准备、开闸、停止是否成功，失败原因和停止回读结果。可复用 `readActual()`、`prepareContinuous()`、`openQGate()`、`stopContinuous()`。 |
| 光谱仪 | 枚举通道、采集波长和原始强度 | 按积分时间、积分延时和采集超时采一组；报告准备完成，支持取消；由会话管理打开和关闭 | 通道是否齐全、每通道数据和失败原因，按需记录同步请求与确认状态。可复用 `probeChannels()`、`captureOnce()` 和会话接口。 |
| 测距仪 | 读取距离、置信度、有效性，可携带采样计数；区分设备返回无效值与通信中断 | 由业务周期读取，基准和窗口配置在业务层 | 提供带观测时间的读数或明确错误。可从 `observeOnce()` 适配，使用现场确认的单位。 |
| 空调 | 读柜内温湿度、开关机、模式、告警和当前设定点 | 核对并写入确认的六项设定点，写后读取实际值，由空调自身调节 | 分别报告环境读数可用性、设备运行状态和设定是否应用成功。可复用 `poll()`、`readParam()`、`setSetpoint()`。 |
| 状态灯 | 下发后回读目标灯态 | 将当前机器状态对应的整组灯态写入设备 | 返回期望灯态、应用是否成功和错误。可复用 `applyAll(..., verify=true)`。沿用现有灯态映射，细分的等待和故障原因显示在 Qt。 |

### 可调参数及生效时机

调试阶段暂时开放以下已讨论的配置项。各项仍按设备或业务规则校验。工艺与连接参数分开保存，界面区分已保存、正在使用和设备已回读确认。

| 类别 | 开放参数 | 生效时机与确认 |
| --- | --- | --- |
| 激光工艺 | 放电电流、脉宽、频率、放电延时、Q 延时、Q 预热。准备稳定等待超时作为软件等待参数开放。 | 检测任务运行中锁定编辑。停止任务后可改，新任务启动时使用。设备准备结果单独回报。 |
| 光谱工艺 | 积分时间、积分延时、采集超时。 | 检测任务运行中锁定编辑。停止任务后可改，新任务使用新值。保留激光和光谱参数组合校验。 |
| 测距业务 | 空带距离基准、来料变化阈值、可测距离下限和上限。 | 运行中可编辑和保存。当前任务继续用启动时的参数快照，下次任务生效。 |
| 空调调节 | 制冷开启和停止温度、加热开启和停止温度、除湿开启和停止湿度。 | Qt 点击「应用」后下发并回读。启动时读取当前设定并与最后确认的目标值比较，只纠正有差异的项，再回读。回读失败或不一致时显示应用失败。 |
| 装机通信与通道 | 相应设备的端口、从站地址、型号和通信超时，灯的命令间隔，以及光谱通道配置等站点参数。 | 可编辑和保存，停止检测任务后重新连接相关设备时生效。当前连接与保存待应用的配置分别显示。 |

待料、超窗及测距通信故障等待期间，工艺参数锁定和测距参数快照继续有效。CRC、寄存器、SDK 句柄和 FPGA 计数由设备层处理。传送带运行控制、检测头自动换带和测量联动留到后续。工控机负责空调设定点，空调自行选择运行方式。

## 已开放的 C++ 调用接口

- `DeviceSession::rangefinder()` 和 `DeviceSession::air_conditioner()` 提供可选设备，未打开时返回空指针。`health` 分别报告是否启用和串口是否打开。串口打开成功后，实际通信状态以设备读写结果为准。
- `Rangefinder::readObservation()` 提供毫米距离、置信度、采样计数和单调时钟时间。读到了设备定义的无效值时，对应字段为空；通信和协议问题返回 `Error`。原始寄存器读取仍可用于诊断。
- `AirConditioner::readEnvironment()` 提供环境、运行和告警读数，状态读取和参数读取各自报告错误。`readSetpoints()` 读取六项当前设定。`applySetpoints()` 先校验全部目标，按设备分辨率比较并写入有差异的项，最后回读确认。写入逐项执行，失败时可重新读取实际值后重试。
- `Spectrometer::captureOnce()` 保留准备完成和取消回调。可选 `incomplete_group` 接收失败组中已收到的通道原始数据；采集失败仍返回错误。采集配置使用 `integration_delay_ns` 和 `timeout_ms`，FPGA 换算在适配器内部完成。旧 C++ `stream()` 已移除，现有 `spectrum_stream` IPC 继续从测量帧队列订阅。
- 激光器和状态灯复用现有控制器接口。测距等待／恢复、空调何时应用配置、任务参数锁定和 UI 都由上层实现。本次设备接口改动没有接入这些任务编排。

站点配置可选加入 `rangefinder` 和 `air_conditioner` 对象。字段与现有串口配置一致，另有 `address`（从站地址 `1–247`）。两项省略时均禁用；启用时填写 `port` 并核对现场的波特率、校验和地址。`timeout_ms` 的可填范围为 `80–10000`。

设备调用同步执行。业务调用者应串行访问同一设备，尤其是空调的轮询和整组设定；关闭或重连会话前需停止相关调用。

## 当前测量需要的操作

| 硬件 | 读 | 写 | 执行 | 业务需要的返回结果 |
| --- | --- | --- | --- | --- |
| 激光器 | `readActual()` 读取工作状态、联锁、急停、过温、故障位、光闸状态，操作记录还使用放电计数 | `prepareContinuous()` 内一次提交放电电流、放电脉宽、放电频率、放电延时、Q 延时、Q 预热；稳定等待上限是软件参数 | 准备并等待就绪、`openQGate()`、`stopContinuous()`。测量任务负责调用时机和运行期门禁复查 | 状态是否可读、是否准备成功、开闸调用结果、停机和光闸回读是否确认、失败原因。需要追溯时保留操作前后状态和计数 |
| 光谱仪 | 启动时 `probeChannels()`，核对枚举与通道信息；采集时读取波长、强度和通道结果 | 每次采集提交积分时间、积分延时和采集超时，适配器内部负责 SDK 配置 | 设备会话负责 `open()` 和 `close()`；测量调用 `captureOnce()`，首组用准备完成回调协调激光，传入取消条件支持停止。独立采集也复用这个入口 | 准备完成、分通道光谱、采集成功或失败原因。分别表达请求同步和物理同步是否已确认 |
| 状态灯 | 下发后回读，定期查询实际灯态 | 提交一组完整灯态，由驱动处理清除旧状态、逐路设置及读回 | 按当前门禁状态刷新灯态，服务退出时置全灭 | 启用时，通信失败和回读不符显示为告警 |

单台设备的读写、协议、时序和清理由设备层完成。业务层持有门禁、激光与光谱仪协同、状态到灯色的映射、采集失败后的业务处置。UI 经命名管道提交业务请求。光谱订阅、落盘和成分预测消费已采到的帧。

### 参数与接口边界

- 工艺参数允许上层调整。激光器用一组会话参数，光谱仪用积分时间、积分延时和采集超时。准备等待、采集等待和设备通信超时分别有自己的含义。
- 装机参数由设备会话或采集计划读取。包括串口配置、灯型号和地址、SDK 路径、光谱通道序列号、主从与 SYNC。连续测量的外触发与单组请求由流程确定。
- 设备实现细节留在驱动，包括串口帧、CRC、FPGA 计数、SDK 句柄及寄存器偏移。故障复位、清计数、TEC 读数和任意寄存器读写可以保留为设备库或维护能力。
- 业务接口按用途设计。一次调用可能包含读、写和执行，例如激光器准备包含配置与读回，灯态应用包含写入与校验。调用方需要知道动作结果、可读性及失败原因。
