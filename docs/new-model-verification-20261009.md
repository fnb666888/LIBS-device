## 首次检查时的主分支兼容性

首次检查时主分支正式部署仍为旧版模型。其 `predict_worker.py` 和 `algorithm_contract.cpp` 有固定的 200–600 nm / 244 维及 v1 标识，`install_model.ps1` 也仅接受 `current_mixed_v1`。所以只替换五个 `.joblib` 不能完成新版接入；模型运行代码、manifest 元数据、窗口、输入校验、界面提示及回归基准必须同步适配。

正式接入前需要明确 564.7293 与 565 nm 的边界处理，并让训练/验证/推理的预处理一致；同时核对真机通道与训练合并谱的响应差异。原项目也记录了训练合并谱 550–565 nm 数据来源尚未核实，这次没有替其解决该问题。
