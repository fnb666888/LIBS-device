# Qt 界面同步

以已经批注确认的网页 Demo 为界面基准。Qt 通过现有命名管道读取设备状态和保存工艺设定，继续由业务服务执行门禁判定。

- [x] 将五台设备集中到仪器参数页。展示全部已开放工艺字段，按设备保存和重读，保留每张卡片的编辑草稿。禁用滚轮调值。
- [x] 使用设备状态快照和门禁判定渲染右置状态灯及悬浮提示。采用光谱标志，清理版面说明和标题，使设备状态卡片等大。
- [x] 将状态灯的试灯预览和测距判定设置保存在 Qt 本地。距离预览读取设备服务的实际观测。暂不启用测距联锁和现场手动试灯。
- [x] 编译并用离线服务验证主界面、五张参数卡和五张状态卡。检查工艺锁定、设备状态映射和缺少设备时的展示。
