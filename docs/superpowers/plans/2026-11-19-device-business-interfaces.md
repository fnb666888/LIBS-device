# 设备业务接口实施计划

**目标**：给业务层提供一期五类设备所需的调用能力。

**依据**：[已确认的一期方案](../../hardware-business-interface.md#已确认的一期方案)。保留测量编排和业务门禁的现有边界。测距和空调默认禁用，使现有站点配置继续可用。

- [x] `Rangefinder::readObservation()` 提供毫米距离、置信度、单调时钟和采样计数。测试有效值、超量程和通信错误。
- [x] `AirConditioner::readEnvironment()` 和 `applySetpoints()` 提供类型化遥测和六项差异写入，全部输入先校验，最终按原始寄存器精度回读。测试未改变时不写、回读不匹配和非法值。
- [x] `SiteConfig`、`DeviceSession` 装配可选测距和空调，独立报告生命周期状态。旧配置默认关闭这两项，空调失联状态不进入现有测量门禁。
- [x] `Spectrometer` 先验证新句柄元数据再提交到缓存，清理无效采集字段并提供部分采集诊断。保留原采集错误和取消语义。
- [x] 更新业务接口文档，运行 Windows x64 MinGW 构建和离线检查（16 套通过）。
