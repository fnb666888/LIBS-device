# SU300 变频器接线、通信与运动调试说明

本文档把 SU-300 系列变频器说明书中的接线、参数和通信规则，映射到本仓库的协议层、设备层和业务层。本文只说明通信与低速调试方法，不替代电气施工、风险评估或急停回路设计。未完成现场核线、绝缘和停机验证前，不得把运动标定门打开。

手册依据：SU-300 series vector frequency converter operating specification manual。重点核对了控制回路图（印刷页 7）、RTU 与寄存器页（印刷页 11-15）、F0/F1 参数页（印刷页 18-23）及 F6 通讯参数页（印刷页 32-34）。手册页码是印刷页码，PDF 阅读器页码可能相差约 3 页。

## 1. 设备边界与软件分层

当前实现把 SU300 放在以下依赖链中：

```text
businessd / motor JSON 命令
        |
business::BusinessFacade::cmd_motor
        |
libs::devices::Su300          同步请求-响应、串口超时、回读
        |
libs::su300                   SU300 帧与寄存器编解码
        |
libs::transport::Link         RS485/COM 字节收发
```

协议层不打开串口，也不决定运动是否允许。设备层只负责下发一帧、检查响应和读取状态。运动业务层负责：

- 运动前读取故障和运行状态；
- 强制要求 `frequency_percent` 与 `duration_ms`；
- 检查配置中的频率、时长和通信看门狗门闩；
- 下发运行后到时停机；
- 读取 `2100H/2101H/2117H` 确认停机；
- 将“没有位置反馈”明确返回给调用方。

SU300 的寄存器没有绝对位置或行程限位状态。当前实现的 `position_feedback` 会标记为未提供，不能把“计时结束”当成“已经到位”。位置切换仍需要外部限位开关和独立的限位输入设计。

## 2. 接线和上电前检查

### 2.1 主回路

手册控制图中的主回路端子为：

| 端子 | 含义 | 备注 |
| --- | --- | --- |
| `R/L1`, `S`, `T/L2` | 变频器输入 | 额定电源和机型必须匹配 |
| `U`, `V`, `W` | 三相电机输出 | 只能接电机，不能接交流输入 |
| `G`/保护地符号 | 保护接地 | 必须可靠接地，手册要求接地阻抗低于 100 Ω |
| `P+`, `PB` | 制动电阻接口 | 按机型和手册图接制动电阻；不能短接 |

接线前切断输入电源。手册要求断电后等待约 5-8 分钟，使直流母线电容放电完成，再打开端子盖或测量。主回路必须由有资质的电气人员施工。变频器输出端不能安装相电容或电阻吸收装置，也不能把输入电源接到 `U/V/W`。

### 2.2 RS485 通信

控制端子图中：

- `A+`：RS485 正端；
- `B-`：RS485 负端；
- `0V`：控制参考地，是否连接要按现场隔离方案和设备说明确认；
- `24V`、`DI0-DI3`、`DO`、`TA/TC`、`10V/V1/AI`：控制、模拟量、开集电极和继电器端子，不是 RS485 数据端。

本项目的 SU300 驱动只使用 `A+`/`B-` 的 RS485 总线，不把 `24V`、`DI` 或继电器端子当作软件运动反馈。A+/B- 使用双绞屏蔽线，并与主回路分开走线；屏蔽层接地方式按现场 EMC 方案确认。A+/B- 不得接到 24 V 或其他控制电源。

最小核线清单：

1. 断电后确认端子编号和极性，不能仅按线缆颜色判断。
2. 确认工控机 RS485 转换器的 A/B 命名与 SU300 的 A+/B- 命名一致；如果总线无响应，只允许在断电后互换 A/B 做一次核对。
3. 确认总线上只有一个有效地址，SU300 `F6-00` 不要设为 0（0 是广播地址，当前驱动只接受 1-247）。
4. 设定与配置一致的波特率、校验、数据位和停止位。
5. 先只读状态，不发送运行命令；串口分析仪应能看到请求、响应、CRC 和响应延迟。

### 2.3 安全回路和限位

手册要求接入急停端子后验证动作有效。急停必须是独立于软件和 RS485 的安全回路，不能用“发一条 2000H 停止命令”代替急停。

SU300 通讯寄存器不提供机械位置或外部行程限位的可靠输入。若电机驱动筛选机构、推杆或挡板：

- 正、反向限位应接入独立的安全/控制输入，并确认是干接点、24 V DI 还是其他模块；
- `DI0-DI3` 的实际功能由 `F2-13` 至 `F2-16` 参数定义；先记录参数，再确认限位是外部故障、外部停机还是方向禁止，不能仅凭端子编号推断；
- 可用 `2114H` 观察输入端子原始位，但当前代码不解释每一位对应的物理限位；
- 需确认限位断开后的硬件动作（禁止哪个方向、是否直接停机）；
- 位置切换未完成限位核实前，业务层只能做受限的短时运动测试；
- 限位接线、急停接线和变频器 RS485 线必须分别验收。

手册把 DI0～DI3 的输入功能放在 `F2-13`～`F2-16`。若限位触点接入这些输入，应在对应参数中选择已确认的外部停机、外部故障或方向禁止动作，并用 `2114H` 观察输入位，再验证 `2117H`/`2101H` 的停机回读。当前代码只返回 `2114H` 原始值，不知道哪个 DI 对应哪个物理限位，也不会替代限位继电器做安全切断；未完成映射前，`position_feedback` 仍不可用。

## 3. 手册参数与推荐初始值

### 3.1 运行命令和频率源

要让 RS485 命令实际控制运行，至少核对：

| 参数 | 手册含义 | 本项目调试要求 |
|---|---|---|
| `F0-02` | 运行命令通道：0 面板，1 端子，2 通讯 | 设为 `2`，否则 2000H 写入可能不成为有效运行命令 |
| `F0-03` | 频率给定：0 面板、1/2 数字给定、3 AI、4 组合、6 通讯 | 设为 `6`，否则 2001H 写入不会成为频率给定 |
| `F0-04` | 最大输出频率 | 不得低于工艺允许的最大频率，且要满足 F0-05/F0-06 的范围 |
| `F0-05` | 上限频率 | 运行频率不能超过此值 |
| `F0-06` | 下限频率 | 运行频率不能低于此值 |
| `F0-07` | 到达下限频率的动作：0 零速、1 下限运行、2 停机 | 低速测试前明确选择，避免误以为“设 0 就停机” |
| `F1-04` | 停机方式：0 减速停机、1 自由停机 | 影响停机确认时间；本项目不会假定写入命令即已停机 |
| `F1-05`-`F1-08` | 停机直流制动参数 | 仅在电机和制动策略已确认后调整，不作为初次通信排障的捷径 |
| `F1-09`/`F1-10` | 正/反点动频率 | 点动动作仍需受最大频率、时长和急停约束 |

`F0-04` 是最高输出频率，`F0-05` 是运行上限，二者不能混写。现场若只修改 F0-05 而 F0-04 较低，仍可能被最大输出频率限制。

### 3.2 F6 通讯参数

| 参数 | 手册定义 | 核对重点 |
|---|---|---|
| `F6-00` | 本机地址，范围 0-247 | 当前驱动使用单播地址 1-247；不要用广播地址测试回读 |
| `F6-01` | 波特率、数据格式、通讯响应方式 | 与 `motor.baud`、`motor.parity`、`data_bits` 一致；默认候选为 9600、8N1；响应方式必须允许主机请求后的正常应答（当前驱动没有配置静默/广播响应模式） |
| `F6-02` | 通讯超时检测时间，0.1-100.0 s；0 表示关闭 RS485 超时检测 | 这是变频器自己的看门狗，不等同于主机一次读写等待 |
| `F6-03` | 本机应答延时，0-200 ms，出厂 5 ms | 主机应允许该延迟；`idle_ms` 是传输 API 的空闲间隔参数，当前 Windows 实现只做参数校验，未把它作为帧结束判据，不是此参数 |
| `F6-04` | RS485 频率给定比例系数 | 初始通常保持 1.00；不要用它代替业务频率上限 |
| `F6-05` | 通讯协议选择：`0=兼容 Delta M`，`1=兼容 MD380`，`2-10=保留` | **不能把 `F6-05=1` 直接写成“本项目实现”。必须按现场机型/厂家确认的兼容协议选择。** |

本项目当前帧实现使用 RTU、功能码 03/06、2000H/2001H/2002H 和 2100H 起始状态寄存器。仅凭“帧看起来像 Modbus RTU”不能推出 F6-05 应为 1。调试时先记录变频器现有 F6-05 值，再用请求/响应和厂家协议确认；没有确认前不要修改该参数。若现场资料明确为 Delta M 兼容，使用 `0`；只有现场资料明确为 MD380 兼容时才使用 `1`。

## 4. RTU 帧和寄存器

### 4.1 帧格式

手册规定 RTU：

```text
地址 | 功能码 | 数据（高字节在前） | CRC Low | CRC High
```

每个字节为 8 个数据位，校验位可选；CRC 为 Modbus CRC16，低字节先发送。支持的功能码：

- `03H`：读寄存器；
- `06H`：写单个寄存器。

手册示例（地址 01H）：

```text
读 2102H、2103H：
发送 01 03 21 02 00 02 6F F7
响应 01 03 04 17 70 00 00 FE 5C

写 2000H=0001H（停机）：
发送 01 06 20 00 00 01 43 CA
正常响应回显同一帧
```

响应必须同时满足地址、功能码、长度、寄存器/值回显和 CRC 校验；只收到一段包含目标字节的串口数据不能当成成功。

### 4.2 本项目写入寄存器

| 地址 | 含义 | 值 |
|---|---|---|
| `2000H` | 通讯运行命令 | `0001` 停机；`0012` 正转运行；`0013` 正转点动；`0022` 反转运行；`0023` 反转点动 |
| `2001H` | 通讯频率给定 | 有符号百分比 ×100；`25.00%` 写 `2500`，反向 `-25.00%` 写 `-2500` |
| `2002H` | 外部命令 | `0001` 外部故障输入；`0002` 故障复位 |

`2001H` 是相对于最大频率的百分比，不是直接写 Hz。实际最高频率仍受 F0-04/F0-05 和业务 `max_frequency_percent` 限制。

### 4.3 本项目读回寄存器

驱动按手册中的保留地址分成四次读取，避免把 `2108H`、`210BH-210CH`、`2110H` 当作有效寄存器：

```text
2100H..2107H（8 个）
2109H..210AH（2 个）
210DH..210FH（3 个）
2111H..2117H（7 个）
```

四个响应会合并为下面的状态：

| 地址 | 内容 | 调试解释 |
|---|---|---|
| `2100H` | 当前故障 | 0 正常；常见码包括过压、过温、变频器/电机过载、外部故障、加/减速过流、欠压、RS485 通讯故障、输出缺相 |
| `2101H` | 运行/停机参数位 | 用于确认运行、停机、点动、方向和通讯给定通道 |
| `2102H` | 设定频率 | Hz×100，原始值除以 100 得 Hz |
| `2103H` | 输出频率 | Hz×100，原始值除以 100 得 Hz |
| `2104H` | 输出电流 | 工程量小数一位，具体单位按机型标定 |
| `2105H` | 母线电压 | 工程量小数一位 |
| `2106H` | 输出电压 | 工程量小数一位 |
| `2109H` | 当前计数值 | 记录原始寄存器 |
| `210AH` | 电机转速 | 记录原始寄存器 |
| `210DH` | 变频器温度 | 工程量小数一位 |
| `2111H` | 脉冲输入频率 | 记录原始寄存器 |
| `2114H`/`2115H` | 输入/输出端子状态 | 只能作为端子状态观测，不能推导机械位置 |
| `2116H` | 状态位 | 记录原始位域 |
| `2117H` | 方向/停机 | `0` 正转，`1` 反转，`2` 停机 |

停止确认至少要同时看 `2117H==2` 或 `2101H` 的停机位，并检查 `2100H` 没有新增故障。若停止命令已回显但状态仍运行，业务层返回 `motor_stop_not_confirmed`，现场必须执行急停，不得继续自动流程。

## 5. 配置和命令接口

### 5.1 站点配置

SU300 默认关闭，先只配置设备打开和只读状态：

```json
{
  "motor": {
    "port": "COMx",
    "baud": 9600,
    "parity": "none",
    "data_bits": 8,
    "timeout_ms": 650,
    "idle_ms": 80,
    "enabled": true
  },
  "motor_address": 1,
  "motor_motion": {
    "commissioned": false,
    "max_frequency_percent": 0,
    "max_duration_ms": 0,
    "stop_timeout_ms": 5000,
    "poll_interval_ms": 100,
    "communication_watchdog_confirmed": false
  }
}
```

- `motor.enabled=true` 只表示打开 RS485 设备；
- `motor_motion.commissioned` 必须保持 `false`，直到现场完成方向、限位、停机和通信看门狗验收；
- `max_frequency_percent` 是软件上限，范围 0-100；
- `max_duration_ms` 是单次动作上限，最大 60000 ms；
- `communication_watchdog_confirmed=true` 只能在 F6-02 失联测试和停机回读均通过后设置；
- `motor.timeout_ms` 是主机一次串口事务的等待上限，不能当作变频器失联保护。
- `motor.timeout_ms` 必须在 1-10000 ms 内，`motor.idle_ms` 不能大于它；这些值会被校验并传给传输层，但当前 Windows 实现只用 `idle_ms` 做合法性校验，不能把它当作 F6-03 应答延迟或帧结束判据的替代品。

### 5.2 `motor` 命令

命令通过 businessd 的 JSON Lines 接口发送。示例：

```powershell
python src\remote\lpc.py motor `
  --pipe \\.\pipe\libs-businessd `
  --args '{"action":"status"}'
```

只读状态不要求运动标定。动作名：

| action | 参数 | 行为 |
|---|---|---|
| `status` | 无 | 分四块读取 `2100H..2117H` 的有效寄存器并返回状态 |
| `reset_fault` | 无 | 写 `2002H=0002`，再读状态 |
| `stop` | 无 | 写 `2000H=0001`，再读状态确认停机 |
| `forward` | `frequency_percent`、`duration_ms` | 正转、到时停机、回读确认 |
| `reverse` | `frequency_percent`、`duration_ms` | 反转、到时停机、回读确认 |
| `jog_forward` | `frequency_percent`、`duration_ms` | 正向点动、到时停机、回读确认 |
| `jog_reverse` | `frequency_percent`、`duration_ms` | 反向点动、到时停机、回读确认 |

运动命令约束：

- 方向由 `2000H` 的正转/反转命令决定；`2001H` 只表示通讯频率给定，正负号不会被业务层用来替代方向命令。当前接口接受 -100.00..100.00，现场应按厂家协议确认负值含义；调试正转/反转时建议先使用同一个正的绝对频率值。
- 频率最多两位小数，范围 -100.00..100.00；
- 必须显式给出 `duration_ms`；
- 请求不能超过 `motor_motion.max_frequency_percent` 和 `max_duration_ms`；
- 发现 `2100H` 故障、通讯错误或停止回读失败时，命令失败；此时执行现场急停。

## 6. 通讯超时的两层含义

必须把以下两种超时分开记录：

1. **主机串口事务超时：** `motor.timeout_ms`。传输层会把 `Reply::timed_out` 置为 `true`，`Su300` 驱动将其转换为 `transport/su300_timeout` 并保留已收到的原始字节。这只说明本次请求没有得到可信响应，不说明电机已经停止。
2. **变频器通信看门狗：** `F6-02`。当变频器在设定间隔内没有收到正确数据时，变频器认为通信故障，并按设备的失联动作策略决定保护停机或维持运行；设为 0 时关闭 RS485 超时检测。

现场确认步骤：

1. 先把 `F6-02` 的当前值和失联动作记录下来，不要直接写参数。
2. 在低速、空载、急停可用的条件下，启动一个很短的动作。
3. 断开 RS485 或停止主机轮询，确认变频器进入手册规定的失联动作。
4. 重新接线后确认故障码、运行位和停机回读。
5. 再把 `communication_watchdog_confirmed` 设为 `true`。

主机响应超时后不能自动宣称“已停机”。如果 RS485 已失联，软件也可能无法下发停止命令；独立急停和硬件限位必须可用。

## 7. 分阶段调试方案

### 阶段 A：断电核线

- 保存变频器原始参数（特别是 F0-02/F0-03/F0-04/F0-05/F0-06/F1-04/F6-00/F6-01/F6-02/F6-03/F6-05）。
- 拍照确认 A+/B-、保护地、电机 U/V/W、急停和限位端子。
- 测量并记录 RS485 线缆连续性和极性。
- 确认电机、变频器、制动电阻和保护地规格；确认电机额定参数已经在变频器中正确设置。

### 阶段 B：只读通讯

- `motor.enabled=true`，运动门闩保持关闭。
- 先发 03H 读取 `2100H..2117H`；确认地址、波特率、校验、CRC 和响应延迟。
- 检查 `F6-05` 当前值，不能把它默认改成 1。
- 若无响应，按顺序排查：COM 口占用、A/B 极性、地址、波特率/校验、F6-01 响应模式、转换器隔离和终端电阻。

### 阶段 C：控制源配置

- 设置 F0-02=2、F0-03=6。
- 设置 F0-04、F0-05、F0-06 为现场允许值。
- 设定 F1-04 的停机方式，并记录减速停机所需时间。
- 保持低速、短时长和急停可用；先只发停机和故障复位。

### 阶段 D：正向短动

- 仍保持低的软件上限，使用最短可控 `duration_ms`。
- 先读状态确认无故障，再写 2001H，随后写 2000H=0012H。
- 到时写 2000H=0001H，读取 2100H、2101H、2117H。
- 写入运行命令收到 FC06 回显后，业务层还会立即读取状态；只有 `2101H` 判定运行、`2117H` 与请求方向一致且 `2100H/2112H` 无故障，才进入计时等待。
- 检查机械方向、输出频率、电流、停机时间和限位动作；任何异常立即急停。

### 阶段 E：反向和点动

- 只在正向和停机验收通过后测试反向。
- 反向前核对电机相序、F0-12 方向限制和机械限位。
- 点动仅用于确认方向和传动链，不得绕过软件上限或硬件限位。

### 阶段 F：失联和限位

- 做 F6-02 通信看门狗断线测试。
- 做正向、反向限位测试；记录限位触发到停机的时间。
- 验证急停在 RS485 断线、业务进程退出和变频器仍运行时都能切断危险动作。
- 通过后才填写正反向行程时间、软件最大频率/时长，并开启 `motor_motion.commissioned`。
