风冷激光器 RS-232 通讯协议整理
=================================

说明：
1. 本文根据用户提供的通讯协议图片整理。
2. 原文中 LD / ld、Q / q 的大小写按语义统一整理；NC 保留原注释。
3. 所有数值如未特别说明，均为十六进制。
4. 电源和 TEC 地址均为 0x00。

一、串口通讯参数
----------------

通讯接口：RS232

串口参数：
- 波特率：38400
- 起始位：1 位
- 数据位：8 位
- 停止位：1 位
- 校验位：无奇偶校验

数据块格式：
- 数据块为 16 进制。
- 2 字节数据：高位在前，低位在后。
- CRC：Modbus CRC-16，低位在前，高位在后。

二、通讯帧格式
--------------

通讯数据帧由 6 个数据块组成：

| 数据块 | 定义 | 长度 |
|---|---|---|
| 1 | 帧头 | 2 Byte |
| 2 | 数据长度 | 1 Byte |
| 3 | 地址 | 1 Byte |
| 4 | 指令 | 1 Byte |
| 5 | 数据 | N Byte |
| 6 | 指令和数据的 CRC 校验 | 2 Byte |

字段说明：
- 帧头：0x5A 0xA5，即 0x5AA5。
- 数据长度：包含地址、指令、数据和 CRC 校验。
- 地址：0x00。
- CRC 校验：不包括帧头和数据长度，仅针对地址、指令和数据进行校验。
- CRC 类型：16 位 CRC，低位在前，高位在后，Modbus CRC-16。

三、LD 电源指令集
================

3.1 设置参数
------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x06 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 见下方指令 |
| 数据 | 2 Byte | 参数值 |
| CRC 校验 | 2 Byte | CRC16 |

电源收到命令后原数发回。

数据说明：
- 数据为 16 进制数。
- 数据长度为 2 个字节。
- 高位在前，低位在后。

参数设置指令：

| 指令 | 含义 | 单位 | 数据范围 / 备注 |
|---|---|---|---|
| 0x11 | 放电电流 | A | 15~100 |
| 0x12 | 放电脉宽 | uS | 50~300 |
| 0x13 | 放电频率 | Hz | 1~10 |
| 0x14 | 放电延时 | uS | 0~500 |
| 0x15 | LD 温度保护阈值 | 0.1 度 | - |
| 0x16 | Q 延时设置值 | uS | 2~500 |
| 0x17 | LD 输出电压限值 | V | 0~130，待机时修改 |
| 0x18 | Q 分频值 | - | 1~10 |
| 0x19 | Q 预热时间 | S | - |

3.2 设置状态
------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x05 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 见下方指令 |
| 数据 | 1 Byte | 状态值 |
| CRC 校验 | 2 Byte | CRC16 |

电源收到命令后原数发回。

数据说明：
- 数据为 16 进制数。
- 数据长度为 1 个字节。

状态设置指令：

| 指令 | 含义 | 数据定义 / 备注 |
|---|---|---|
| 0x20 | 设置地址命令 | NC |
| 0x21 | 工作状态 | 0：不工作；1：工作 |
| 0x22 | 内外时钟状态 | 0：内时钟内 Q；1：外时钟内 Q；2：外时钟外 Q；待机时修改 |
| 0x23 | 暂停/恢复放电时钟 | 0：暂停放电时钟；1：恢复放电时钟 |
| 0x24 | 光闸状态 | 0：光闸关；1：光闸开；控制 Q 信号的有无 |

3.3 保存数据 / 复位 / 单次触发
-----------------------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x04 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 见下方指令 |
| CRC 校验 | 2 Byte | CRC16 |

电源收到命令后原数发回。

数据说明：
- 无数据。

指令：

| 指令 | 含义 |
|---|---|
| 0x31 | 保存参数到 EEPROM |
| 0x32 | 计数器清零 |
| 0x33 | 故障复位 |
| 0x34 | 单次触发，分频数为 0、Q 打开时有效 |

3.4 读取设置数据
----------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x04 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 0xB1 |
| CRC 校验 | 2 Byte | CRC16 |

电源回送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x16 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 0xB1 |
| 数据 | 18 Byte | 设置参数数据 |
| CRC 校验 | 2 Byte | CRC16 |

返回数据定义：

| 数据位 | 含义 |
|---|---|
| data[0] | 放电电流高位 |
| data[1] | 放电电流低位 |
| data[2] | 放电脉宽高位 |
| data[3] | 放电脉宽低位 |
| data[4] | 放电频率高位 |
| data[5] | 放电频率低位 |
| data[6] | 放电延时高位 |
| data[7] | 放电延时低位 |
| data[8] | Q 延时高位 |
| data[9] | Q 延时低位 |
| data[10] | LD 温度保护阈值高位 |
| data[11] | LD 温度保护阈值低位，NC |
| data[12] | LD 电压输出限值高位 |
| data[13] | LD 电压输出限值低位 |
| data[14] | Q 分频高位 |
| data[15] | Q 分频低位 |
| data[16] | Q 预热时间高位 |
| data[17] | Q 预热时间低位 |

3.5 读取实际数据
----------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x04 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 0xB2 |
| CRC 校验 | 2 Byte | CRC16 |

电源回送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x1A |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 0xB2 |
| 数据 | 22 Byte | 实际状态数据 |
| CRC 校验 | 2 Byte | CRC16 |

返回数据定义：

| 数据位 | 含义 |
|---|---|
| data[0] | 工作状态：0=未工作；1=正在工作且放电；2=自适应中；3=正在工作未放电 |
| data[1] | 时钟状态：0=内时钟；1=外时钟内 Q；2=外时钟外 Q |
| data[2] | 故障状态，将该字节换算成 8 个 bit |
| data[3] | 联锁状态 1：0=联锁 1 短接；1=联锁 1 断开 |
| data[4] | 联锁状态 2：0=联锁 2 短接；1=联锁 2 断开 |
| data[5] | 急停状态：0=正常状态；1=急停状态 |
| data[6] | 过温状态：0=正常状态；1=过温状态 |
| data[7] | LD 温度高位 |
| data[8] | LD 温度低位，单位：0.1 度，负温为补码（无） |
| data[9] | 实际电流高位 |
| data[10] | 实际电流低位，单位：A |
| data[11] | 实际电压高位 |
| data[12] | 实际电压低位，单位：V |
| data[13] | 计数器最高位 |
| data[14] | 计数器次高位 |
| data[15] | 计数器次低位 |
| data[16] | 计数器最低位，单位：次 |
| data[17] | 散热器温度高位 |
| data[18] | 散热器温度低位，单位：0.1 度，负温为补码（NC） |
| data[19] | Q 闸设置状态：0=关；1=开 |
| data[20] | 工作设置状态：0=关；1=开 |
| data[21] | 时钟设置状态：0=关；1=开 |

故障状态 data[2] bit 定义：

| Bit | 含义 |
|---|---|
| Bit7 | 芯片错误 |
| Bit6 | MOS 管故障 |
| Bit5 | 输出电压超过限制 |
| Bit4 | 直流源故障 |
| Bit3 | 接地故障 |
| Bit2 | 自适应故障 |
| Bit1 | 输入欠压 |
| Bit0 | 输出过流 |

四、TEC 指令集
==============

4.1 设置 TEC 参数
-----------------

上位机给电源发送：

| 字段 | 长度 | 固定/示例值 |
|---|---:|---|
| 帧头 | 2 Byte | 0x5AA5 |
| 数据长度 | 1 Byte | 0x06 |
| LD 地址 | 1 Byte | 0x00 |
| 指令 | 1 Byte | 见下方指令 |
| 数据 | 2 Byte | 参数值 |
| CRC 校验 | 2 Byte | CRC16 |

电源收到命令后原数发回。

数据说明：
- 数据为 16 进制数。
- 数据长度为 2 个字节。
- 高位在前，低位在后。

TEC 参数设置指令：

| 指令 | 含义 | 单位 / 备注 |
|---|---|---|
| 0x80 | 保存 TEC 参数 | 数据填 00 00 即可 |
| 0x81 | 最大温度设置 | 0.1 ℃ |
| 0x82 | 最小温度设置 | 0.1 ℃ |
| 0x83 | B 值 | 1 |
| 0x84 | 热敏电阻标称值 | 0.1 kΩ |
| 0x85 | 前级电压设置 | 0.1 V |
| 0x86 | TEC 电压设置 | 0.1 V |
| 0x87 | Kp 设置 | 0.1 |
| 0x88 | Ki 设置 | 0.1 |
| 0x89 | Kd 设置 | 0.1 |

五、帧长度速查
==============

| 功能 | 指令 | 发送数据长度字段 | 返回数据长度字段 |
|---|---|---:|---:|
| 设置 LD 参数 | 0x11~0x19 | 0x06 | 原数返回 |
| 设置状态 | 0x20~0x24 | 0x05 | 原数返回 |
| 保存/清零/复位/单次触发 | 0x31~0x34 | 0x04 | 原数返回 |
| 读取设置数据 | 0xB1 | 0x04 | 0x16 |
| 读取实际数据 | 0xB2 | 0x04 | 0x1A |
| 设置 TEC 参数 | 0x80~0x89 | 0x06 | 原数返回 |
| 读取 TEC 设置数据 | 0xBC | 0x04 | 0x1A |
